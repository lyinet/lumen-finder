# Lumen for Alfred

- `lf 年终总结` — search by name, pinyin (`nzzj`), folder or the words inside files
- `la 北海道的雪景视频` — search by meaning

↵ open · ⌘↵ reveal in Finder · ⇧ Quick Look. Needs Lumen.app in /Applications
(Alfred Powerpack, for workflows). Each release attaches `Lumen.alfredworkflow`;
to build it yourself: `cd integrations/alfred && zip -r ../../Lumen.alfredworkflow info.plist`.
